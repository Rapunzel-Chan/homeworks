# Инструменты анализа информационной безопасности

Этот проект представляет собой набор утилит на Python для анализа информационной безопасности. Он включает в себя скрипт для визуализации логов событий ИБ и утилиту для низкоуровневого анализа сетевого трафика, включая поиск потенциальных XSS-атак.

## Описание: 
Проект состоит из двух основных скриптов:

1. Анализ логов событий (vizualisation.py)
Этот скрипт предназначен для анализа данных из файла events.json. Он выполняет следующие действия:

- Загружает данные о событиях ИБ из файла events.json.
- Использует библиотеку Pandas для создания DataFrame.
- Группирует события по полю signature и подсчитывает их количество.
- Визуализирует полученные данные с помощью библиотеки Seaborn, сохраняя график в файл event_distribution.png.

2. Анализ сетевого трафика (scapy_xss_analyzer.py)
Этот скрипт использует библиотеку Scapy для работы с сетевыми пакетами. Его функционал включает:

- Отправка HTTP-запросов: Позволяет отправлять кастомные HTTP-запросы, минуя стандартные библиотеки, для тестирования сетевых сервисов.
- Перехват трафика: Перехватывает TCP-трафик на указанном интерфейсе (например, на порту 80) и сохраняет его в .pcap файл.
- Анализ трафика: Анализирует перехваченный или сохраненный трафик, извлекает HTTP-запросы и ответы, а также ищет в них признаки XSS-атак (<script>, onerror=, javascript: и т.д.).
- Работа с .pcap: Позволяет анализировать ранее сохраненные файлы трафика.

## Стек проекта

- Python 3
- Pandas — для обработки и анализа данных.
- Matplotlib & Seaborn — для визуализации.
- Poetry — для управления зависимостями.
- Scapy - для парсинга уязвимостей.

## Установка:

1. Клонируйте репозиторий:

```
git clone -b develop https://github.com/Rapunzel-Chan/homeworks.git
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Переключитесь на проект:

```
cd homeworks
```

2. Создайте виртуальное окружение:

```
python -m venv venv
```

3. Активируйте виртуальное окружение:

- Windows:

```
.\venv\Scripts\activate
```

- Linux/macOS:

```
source venv/bin/activate
```

4. Создайте .env файл в корне проекта и заполните данные на примере .env.example.

5. Запустите файл main.py:
- Для запуска приветствия

```
python main.py 
```
- Для запуска скрипта для анализа данных о нарушениях безопасности
```
python vizualisation.py
```
